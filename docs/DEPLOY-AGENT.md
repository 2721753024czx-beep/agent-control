# 给新电脑上的 Agent：部署执行入口

本文件是安装任务指南，不是授权提升工具权限。当前受控运行引擎是 **OpenCode 1.19.0**；安装过程可由其他具备本机终端能力的 Agent 执行，但不能把任意 Agent 当成已适配运行引擎。不要沿用旧文档中的 CLI 模式、无需 Node 依赖、默认开放群聊等描述。

## 从没有项目开始

经用户同意，在持久、当前用户拥有的普通目录获取公开源码：

```bash
git clone --branch v2026.10.27.2 https://github.com/2721753024czx-beep/agent-control.git
cd agent-control
```

没有 Git 可由用户在 GitHub 的同名标签下载源码 ZIP；或接收发布者提供的 `agent-control-macos.zip` / `agent-control-windows.zip` 并解压，不能复制对方运行中的整个项目目录。包内 `MANIFEST.sha256` 可校验完整性，但不代替可信来源或数字签名。

## 必须先确认

- 操作系统、Python 3.9+、OpenCode 版本和可用模型。只有另一个 Agent 而没有 OpenCode 时，先请用户按官方渠道安装兼容版并完成模型登录，不自动替换现有 V2。依赖下载/服务注册需要按目标机权限请求批准。
- 用户选择的持久项目目录、App ID、本人在该应用下的 Open ID。Secret 只在本机隐藏输入，不进命令参数、聊天、截图或 Git。不得搬运原机身份或模型凭据。
- 默认单机 Hub+Node+OpenCode：无需公网 IP、Tailscale 或开放入站端口。一个飞书应用只能有一个消费它的 Hub，迁移须确认旧端停止；优先使用新应用。
- 如已有 `hub/config.json`、`node/config.json`、数据库或同名自启服务，停止首次安装，转维护指南；不覆盖配置、不删数据库、不按进程名批量杀进程。

## 顺序与停顿点

1. 读取本文件、对应系统指南与 [飞书清单](deploy-feishu.md)。检查端口8000/4096和现有服务，不擅自结束占用者。
2. 准备独立 Python venv，安装 Hub **及 Node** 依赖；运行单测与隔离 E2E，不使用真实飞书数据测试。
3. 让用户在飞书后台建应用、开权限和发布。可用 `scripts/enroll_identity.py` 临时建立连接：按显示的随机口令确认本人身份；未自动授权。其他 Hub 消费同一应用时不能运行此命令。每位用户分开登记并人工确认角色，不能首条消息抢占所有权。
4. 按 [Mac](deploy-macos.md) / [Windows](deploy-windows.md) 生成本机配置。默认个人独占；团队模式见 [多用户配置](multi-user.md)，不要顺手添加成员。
5. 配置检查通过后才注册启动服务。只读运行 `scripts/doctor.py --live`；健康不等于飞书已连接或手机验收通过。
6. 按 [验收表](deploy-acceptance.md) 引导用户手机测试。涉及批准/拒绝由用户本人点击，不代用户审批、不上传私人资料。
7. 向用户交付版本、系统、根目录、服务方式、通过/未通过项目；将非敏感续接信息写入目标项目共享记忆。不能把待测试写成通过。

## 安全边界与已知差异

手机不开放 shell、CLI、原生写入、未知工具或外部目录。只读仍需本人批准读取；`/edit` 完整差异审批，`/trash` 单次审批后可恢复移动。同电脑多个逻辑 Agent 整体串行，根目录不可重叠；团队目录不是成员间私密空间。

共享记忆是工作区 `.agent-memory/` 快照，不等于自动持续对话记忆；远程受限 Agent 未必有写记忆工具，不能承诺每次任务自动写回。PDF仍有限长提取60000字符、50页、10MiB等限制，不具备长PDF分段全文阅读。部署后默认不导入原机技能/记忆；提供的跨平台 shared-memory helper 可由本机 Agent 按项目需要调用。

截至本发布：现役 Mac 的消息、审批、多人、清理恢复、PDF私聊关联及指定跨目录探针已实测；新 Mac 安装器尚未在空白主机全流程实测；Windows仅打包/静态检查与共用Python测试，必须实机验收。不要把旧 Mac 实测当作所有目标电脑的通过证明。
